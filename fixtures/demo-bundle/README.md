# Demo recipes

Five recipe versions (four dishes) written for mise, in the [seed bundle format](../../docs/seed-bundle.md). They
are the data for the browser journeys (`web/e2e/`) and the demo install, and contain nothing from any other source.
They're under the repository's MIT licence.

They are small on purpose, but each exercises something:

| Dish | What it covers |
| --- | --- |
| Weeknight Tomato Pasta | Published at 2 and 4 servings; a pinch (red pepper flakes); a bare count with its own word (1 onion); step amounts with "(… for 4 servings)" |
| Lemon Herb Chicken | A packet with a known size (stock concentrate, "1 packet (2 tsp)"); pan-sauce water that partly boils off |
| Black Bean Tacos | Two versions of one dish (Cheddar, then Monterey Jack), linked by lineage |
| Garlic Rice Bowl | Published at one serving count only, so every other count is scaled |

Garlic, onion and olive oil appear in several dishes, so a week's shopping list has lines to add up.

| File | What |
| --- | --- |
| `variants.ndjson` | The recipes; generated by `build.py` (edit there, run `python fixtures/demo-bundle/build.py`, commit both) |
| `curation.json` | Store sections and count words for their foods (`mise food apply`) |
| `manifest.json` | The bundle's source key (`seed:mise-demo`) |

To load them into a database: `mise migrate`, `mise import-bundle fixtures/demo-bundle`, `mise match-foods`,
`mise food apply fixtures/demo-bundle/curation.json`, `mise group-dishes`, `mise derive-options`, `mise parse-steps`
(what `web/e2e/serve.mjs` does).
